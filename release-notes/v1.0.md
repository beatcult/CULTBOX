# CULTBOX 1.0

The first release of CULTBOX, a three-channel groovebox for the M-VAVE FM-1.

**Install:** download `cultbox.fwsc` and install it with the [FM-1 Firmware Hub](https://thefirmwarehub.com) or any
M-UPGRADE web installer (or `python3 tools/fm1_install.py cultbox.fwsc`). Package identity **FM-1_666666**. Install any
other firmware the same way to leave it; hold **OCT-** at power-on for the USB rescue.

**What is in it**
- **DRUMS:** ten Elka Drummer One pads with a kick sub, a step sequencer (swing, chance, slide, per-step edits), seven factory patterns.
- **PLVKS:** a Polivoks-style duophonic voice with presets, arpeggiator, scales and a recordable note sequencer.
- **DUB:** a dub siren with glide on the keys.
- **Mix:** levels, echo sends and **pan** on its own page (two voices can be hard-panned into separate mixer channels), two echoes that can follow the tempo, and per-channel vintage, saturation and tape.
- Works on both flash chips found in FM-1 units (Puya P25Q80 and the newer UC25HQ80), in the app and in the update loader.
